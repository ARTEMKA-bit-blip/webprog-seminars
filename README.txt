Папки відповідають семінарам:
s1_html_css      семінар 1  — HTML/CSS (index.html + styles.css)
s2_js_dom        семінар 2  — JavaScript і DOM (app.js: показ форми, форма, список з масиву, лічильник)
s3_fetch         семінар 3  — fetch, meetings.json, відкритий API, фільтр за днем, поле host
s4_async_post    семінар 4  — async/await, форма POST, email, «Мої заявки», тайм-аут 5 с
s5_s6_server     семінари 5–6 — Express: GET/POST/PUT/DELETE, фільтр ?day, JSON 404, заявки (400/404/409)
s9_s10_final     семінари 9–10 — фінальний проєкт (SPA, адаптивність, безпека, готовність до публікації)
Семінари 7–8 уже здані окремо (club-local).

Запуск s1, s2: відкрити index.html.
Запуск s3, s4: python -m http.server 8000 у папці, потім http://localhost:8000
Запуск s5_s6 і s9_s10_final: npm install, npm start, http://localhost:3000
